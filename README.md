Entry for the make.fun competition [The Word You'd Delete From the Dictionary](https://make.fun/bounty/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2).

A program/v1 entry: `main.py` writes one word to `/output/entry.txt`. The word is fixed, so every run produces byte-identical output within the gate (UTF-8, 1–77 characters, one word).

The word:

> queue

Five letters, one sound — four of them silent. Deleting it erases a word that barely does any work, and the joke is visible in the spelling the instant you read it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
